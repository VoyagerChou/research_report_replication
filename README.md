## 2. 风险模型层(DRM,全市场共享)

自建深度风险模型(`model_core/deep_risk_model.py` + `input_data_update/build_drm.py`):

- 结构:隐式图 GAT(截面注意力取残差)+ 双支 GRU,各出 K/2 个因子,K=10;
- 输入 (n,40,15) = 5 量价比值(÷窗末、截面 5×MAD 去极值) ⊕ 10 Barra 暴露;标签 = 未来 20 日逐日收益;
- 损失 = 多期非中心化残差 R²(逐期 y_{t+h} 自投影)+ λ·tr((FᵀF)⁻¹) VIF 正则,λ=0.01;
- 滚动:**2013–2026** 逐年一个 PIT 模型,训练窗 4 年、尾部 10% 验证、防泄露砍尾,逐年热启动保持因子身份连续;
- 推理:年度模型对当年逐日打分,截面 z 后落 `deep_risk_exposure_daily/`。

两条下游(装配于 `build_drm`):
`expo.dat` (T×J×10) 作为个股输入的后 10 维;
每日涨幅前 10% 股票的 10 因子截面均值,经 {5,10,20,40} 日窗 × {均值, std, 放大性} 展开为 120 维,
与 idx63 拼接为 **183 维市场状态**(`market_state.npz`)。

> **暖启动是必须的**：曾因年度模型全部冷启动导致因子身份跨年断裂（相邻年对角相关仅 0.20），
> 修复后 IR 0.81 → 1.13。`run` 前建议跑一次暖链自检（见第 6 节 `tools/`）。

## 3. 面板装配与训练池

`assemble_panel` 将上述产物装配为 `panel.npz`,训练与评价只读此文件。

- 个股输入 (n,40,70) = 7 量价(÷窗末、截面 MAD) ⊕ 53 因子(逐日全市场 z) ⊕ 10 DRM 暴露(原值);
- 市场状态取当日 183 维向量,经训练窗拟合的 robust-z 后输入双门控(63 维旧门 + 120 维新门 + 全连接融合),输出 70 维特征权重乘于输入;

> 注：53 因子的**内容不进面板**（面板只存日历/池/标签/市场状态），因此更换因子源无需重装面板。

## 4. 建模层(两条因子线)

**静态 MASTER**(`update/master_score.py`,对照线):
三段注意力骨干(输入投影+正弦位置编码 → 股票内时序注意力 4 头 → 逐时间步截面注意力 2 头 → 末时刻 query 时序聚合 → Sigmoid),
损失为加权 MSE(w=Sigmoid(γ(ŷ−0.5)),γ=5,多头端加权)。
OOS 年 Y 的模型以 [Y−6, Y−2] 训练、Y−1 验证(标签不越入 OOS 年),验证 wMSE 早停;
**2019–2024** 逐年训练并对当年逐日打分,当年内模型冻结（对照线覆盖至 2024;主线覆盖全区间 2019–2026）。

**DoubleAdapt 元增量**(`model_core/meta_train.py` + `update/update.py`,**交付主线**):
在 MASTER 骨干(φ)之上加数据适配器(ψ):特征适配 G 与 logit 域标签适配 H/H⁻¹(8 头余弦门控,τ=10)。
- 离线元训练(2013–2017):FOMAML 双层优化 —— 内层对 φ 走一步继承状态 Adam 得适应量,
  外层在 query 上经 H⁻¹ 计算 wMSE 并更新 φ+ψ,附 REINFORCE 标签正则(reg=0.05, σ²系数=0.167);
  以 2018 年轨迹验证(与在线同构)的 wMSE 早停;φ 冷启动(可切换为载入预训练 MASTER 暖启动);
- 在线元增量(**2019–2026**):每 20 个交易日一个更新节点,元更新 → 以最近已实现标签块做内层适应 → 节点窗内逐日打分,
  按年分片落库,断点续跑与不中断逐位一致。**离线只训一次,此后永远靠增量**（这是元增量学习对滚动重训的替代，
  见民生《从增量学习到元学习》p3/p5/p12）。

## 5. 评价层

`evaluate/factor_eval.py`,两层口径:

- 因子层:周频 RankIC(因子值对未来 10 日 vwap 收益的 Spearman)、周度/年化 ICIR、IC 胜率;
- 组合层:十分组、双周调仓、最高分组等权满仓、T+1 vwap 成交、双边千三、涨跌停门;
  **收益与风险按日频核算**(组合按收盘盯市、换仓日拆腿经 vwap 成交、基准=指数日收盘同窗对齐、超额净值=Π(1+r_p−r_b) 日频复利):
  绝对收益/超额净值年化/超额波动率/信息比率/夏普/期胜率(双周)/超额MDD(日频)/
  多空(双周分组)/单边年化换手,分年度(区间累计)与全样本(重算 CAGR)。

全 A 因子分别映射至三个指数成分内独立排序回测(基准为对应指数),另设全市场层(基准为中证800)。

## 8. 已知局限

1. **2026 上半年因子失效**：超额 −15.2%，多空转负 −9%，IC 胜率 48%——整条排序反向而非头部问题，
   12 次在线元更新未能拉回。是当前最大未解问题。
2. **年度滚动在年界造成因子断点**：DRM 暴露的日度自相关从年内 0.980 掉到年界 0.843。
   已用两个独立检验确认对因子表现无可归因影响（年初 IC 谷底落在年内第 11–40 日而非 1–10 日，
   与机制预期相反；断点深度与年初 IC 差的相关性 Spearman −0.14 / p=0.79，n=6），故记录不修。
3. **两处官方机制未实现**：DRM 的预测指数平滑 `rho=0.99` 与梯度累积 `update_freq=64`
   （论文 arXiv:2107.05201 p5）。团队现有 DRM 交付同样没有。二者与学习率强耦合，须成对处理。
4. **缺口形态**：越往小盘达成率越低（沪深300 内 74%、中证500 内 48%、中证1000 内 42%、全A 58%），
   且集中在 2020 / 2024 两个风格切换年。

## 9. 已排除的候选（附依据，避免重复投入）

| 候选 | 结果 | 依据 |
|---|---|---|
| d_model 128 / 256 | −4.3 / −2.8pp | 官方值 256 在复现设定下不迁移 |
| β = 2 / 3 | 平（d64）/ 更差（d≥128） | 门控输入含 120 维噪声偏大的衍生量，尖锐门控放大噪声 |
| γ = 10 | 全样本打平（池内略优、2024 更脆） | 研报区间 [5,10] 内两值均合规，取下界 |
| H 仿射域 | 显著更差 | 有界标签做平直仿射会撞 Sigmoid 天花板 |
| wMSE 权重挂标签 | 未优于 | — |
| DRM 路演稿参数组（窗20/drop0.5） | −3.3pp | 虽更接近论文原值，但在复现管线里更差 |
| 训练模式包（epoch0 基线 + plateau 退火 + 可学内层 lr） | 未优于 | — |
| dropout 0.1 + β3 + γ10 组合 | 未优于 | — |
| 团队 53 因子 | −4.8pp（同窗） | 差距源于 3 处可修复的实现问题，见下 |
| DRM `rho=0.99` 平滑 | 不做 | 复现无 ρ 时年内自相关已达 0.980，论文含 ρ 为 0.989，边际 0.01 |
| 年度重训元学习 | 不做 | 元增量学习本就是滚动重训的替代品（民生 DoubleAdapt 研报 p3/p5/p12） |
| 更换 53 因子名单 | 不做 | 与研报附录逐字一致 53/53 |

**种子噪声带 = 3pp**（同参数三种子标定），是判读一切差异的尺子。

团队 53 因子的三处问题（供反馈）：`turnover_stdrate_1m/3m/6m` 截面呈针状（z 化后近似死通道）、
三对完全重复列（`swap_1m ≈ turnover_mean_1m` 等，相关 0.9999）、`vwap_5d_60d` 使用未复权价。
